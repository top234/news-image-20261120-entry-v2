# news-image-20261120 — v2 entry

One image summing up the world news of Friday 20 November 2026, for the
make.fun competition https://make.fun/bounty/news-image-20261120.

- `main.py` — Python 3.13 stdlib-only entrypoint: copies `entry.png` to
  `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`).
- `entry.png` — the 1024x1024 front page, drawn procedurally (PIL) by the
  builder: headline "GUILTY OF GENOCIDE" (the World Court rules Myanmar
  guilty of genocide against the Rohingya — the first such verdict ever
  against a state), plus Kyiv under fire, the Trump–Xi–Putin summit in
  Shenzhen, and tumbling markets.
